# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash-based calculator that computes simple interest based on three user inputs:

* Principal amount
* Rate of interest
* Time period

The calculator takes these values from the user and calculates the simple interest using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

## Features

* Accepts principal amount as input
* Accepts rate of interest as input
* Accepts time period as input
* Calculates simple interest
* Displays the calculated simple interest to the user
* Simple and easy-to-use Bash script

## Formula

```text
Simple Interest = (P × R × T) / 100
```

Where:

* **P** = Principal amount
* **R** = Rate of interest
* **T** = Time period

## Technologies Used

* Bash
* Shell scripting

## How to Run

Make sure Bash is installed on your system.

Run the following command:

```bash
bash simple-interest.sh
```

Enter the principal amount, rate of interest, and time period when prompted.

## Example

```text
Enter the principal amount: 10000
Enter the rate of interest: 5
Enter the time period: 2

Simple Interest: 1000
```

## Project Purpose

This project demonstrates basic Bash scripting concepts such as taking user input, performing arithmetic calculations, and displaying output.
